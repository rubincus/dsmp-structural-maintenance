# DSMP Structural Maintenance

Simulation-based Bayesian decision framework for risk-resilience structural maintenance prioritization under epistemic uncertainty.

The project implements a reproducible Dynamic Structural Maintenance Prioritization (DSMP) workflow that converts uncertain structural evidence, simulated degradation, consequences, recovery exposure, graph descriptors, and resource constraints into auditable maintenance decisions. This repository contains only the computational implementation, bridge/FEM demonstration data, and reproducibility results; document sources are intentionally excluded.

## Decision workflow

The DSMP model links four layers:

1. **Bayesian evidence updating:** inspection/count evidence is converted into predictive failure probabilities using a Gamma-Poisson model.
2. **Risk-resilience scoring:** failure probability, consequences, recovery-time exposure, and epistemic uncertainty are combined in an interpretable priority score.
3. **Decision routing and optimization:** value-of-information (VoI) logic, graph-aware descriptors, and budget/capacity constraints guide inspection, monitoring, repair, reinforcement, replacement, or deferment.
4. **Simulation-based validation:** an independent degradation and limit-state simulator supplies ground-truth probabilities and oracle preventable losses for calibration, regret, ranking, robustness, and Pareto-feasibility checks.

All reported datasets are generated by the executable simulation protocol; the repository does not claim field validation.

## Model-to-code map

| Component | Code location | Purpose |
| --- | --- | --- |
| Parameters and weights | `code/dsmp_code_package/src/dsmp/config.py` | Scoring weights, thresholds, budgets, action costs, and simulation settings. |
| Simulated portfolio | `data_generator.py`, `validation_experiments.py` | Generates assets, degradation states, evidence quality, consequences, recovery exposure, and validation ground truth. |
| Bayesian updating | `bayesian.py` | Gamma-Poisson updating, predictive probability, and posterior variance. |
| Consequence and uncertainty normalization | `normalization.py`, `epistemic.py` | Consequence, recovery, data-quality, discrepancy, and epistemic terms. |
| DSMP score and action labels | `scoring.py` | Priority score and threshold-based action mapping. |
| Value of information | `voi_gate.py` | Inspection/monitoring routing for uncertain assets. |
| Constrained planning | `optimization.py`, `validation_experiments.py` | Budget- and crew-constrained maintenance plans and comparators. |
| Graph-aware descriptors | `graph_augmented.py`, `validation_experiments.py` | Centrality and cascade-susceptibility terms. |
| Validation metrics | `validation_metrics.py` | Calibration, ranking, bootstrap, paired tests, and rank-reversal diagnostics. |
| Main validation protocol | `validation_experiments.py`, `scripts/run_all.py` | Reproduces the 300-asset, 50-seed validation. |
| Supplementary analyses | `revision_experiments.py`, `scripts/run_revision_experiments.py` | Weight sensitivity, multi-seed ablation, cross-seed recalibration, and base-rate diagnostics. |
| Figure regeneration | `figures.py`, `scripts/regenerate_figures.py` | Recreates methodological and validation figures from stored results. |

Paths shown without a prefix in the table are relative to `code/dsmp_code_package/src/dsmp/`.

## Installation

From the repository root:

```powershell
Set-Location code/dsmp_code_package
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .
```

For tests:

```powershell
pip install pytest
python -m pytest
```

## Base workflow

```powershell
Set-Location code/dsmp_code_package
python run_all_experiments.py --out output
```

## Main validation protocol

```powershell
Set-Location code/dsmp_code_package
python scripts/run_all.py --seed 42 --out validation_results_50x256 --n-assets 300 --seeds 50 --mc-paths 256
```

The archived protocol-scale outputs are stored in `results/validation_results_50x256/`.

## Supplementary analyses

The added protocol reproduces the following analyses:

- S1: multi-seed sensitivity over the DSMP weight simplex;
- S2: multi-seed score ablation under one common action-selection rule;
- S3: cross-seed Platt/isotonic recalibration on held-out portfolios;
- S4: event base rate, irreducible Brier component, and Brier skill scores.

Run the complete protocol with:

```powershell
Set-Location code/dsmp_code_package
python scripts/run_revision_experiments.py --seed 42 --n-assets 300 --seeds 50 --mc-paths 256 --out revision_results
```

The verified outputs from that configuration are stored in `results/revision_results/`.

To regenerate the reporting figures from the stored validation tables:

```powershell
python scripts/regenerate_figures.py --methodological `
  --tables ../../results/validation_results_50x256/tables `
  --out regenerated_figures
```

## Bridge/FEM demonstration files

`bridge_fem_model/` contains the bridge-generation script and the CSV tables used to demonstrate how FEM-derived structural information can enter the DSMP decision workflow. These files are an interface and visualization demonstration, not empirical validation of the maintenance policy.

## Scientific scope

This repository provides a simulation-based computational decision framework for reproducibility, auditability, and controlled benchmarking. Field deployment requires site-specific structural models, inspection histories, monitoring data, calibrated deterioration processes, intervention-effect models, and engineering review.
